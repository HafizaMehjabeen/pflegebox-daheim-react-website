# Pflegebox Daheim: Healthcare Website

A modern German healthcare website that makes it simple to request free medical care supplies.

**Live site:** https://pflegebox-daheim.de
**My role:** UI/UX design in Figma and React development

## What I did

- Designed the complete UI/UX in Figma
- Built the responsive site with React
- Clear product selection flow and custom Pflegebox configuration
- Consultation booking
- Accessibility-focused layouts for users and families

## Stack

React, Figma, responsive design
